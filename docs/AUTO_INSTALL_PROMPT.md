安装后请用诊断结果确认当前聊天 mounted=true，汇报安装位置、缓存与日志位置、卸载命令以及当前版本的兼容性限制。不要将浏览器预览当成原生客户端挂载成功，也不要宣称未经验证的平台或客户端版本已经通过实机测试。仅访问本机回环调试端口，不开放公网。除非我另外要求，不要修改我的压缩阈值或自动兑换重置卡。
